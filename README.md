**Purpose:**
A2I-Copilot is a **conversational AI assistant** designed for **contextual analysis of enterprise datasets**, using RAG-based reasoning to answer queries and provide actionable insights.

**Features:**

* Retrieval-Augmented Generation (RAG) reasoning
* Conversational interface for data exploration
* Supports structured, unstructured, and simulated enterprise data
* Generates narrative insights and contextual explanations

**Tech Stack:**

* Python, LangChain, LLMs (Azure OpenAI / HuggingFace models)
* Streamlit or FastAPI for conversational interface
* PostgreSQL / simulated dataset integration
* Dockerized deployment for reproducibility

**Usage:**

```bash
# Clone the repo
git clone https://github.com/atsuvovor/CyberThreat-Insight.git

# Navigate to A2I-Copilot
cd CyberThreat-Insight/A2I-Copilot

# Run the copilot demo
streamlit run copilot_demo.py
```
